# Vault Gold card design (saved for later)

This is the navy-and-gold spot card design: Pokémon artwork on a dark background on the front, and a gold vault dial with "Crack the Vault" on the back. It's saved here to use later. For now, the deck keeps its original design so every card matches.

- `full-deck-double-sided.pdf`: all 32 cards from the updated spot sheet, ready to print double-sided.
- `updated-cards-plus-vault-box-double-sided.pdf`: the 6 changed or lost cards plus a Vault Box card (`--vault-card`).
- `spot-cards.py`: the generator snapshot that makes this design. Run it from the repo root: `python3 printables/designs/vault-gold/spot-cards.py`. Add `--only Greninja` to reprint a single card.

Print settings: 100% / Actual size, double-sided, flip on long edge. Cards are 2.5" × 3.5" and fit a 3×4 toploader.
